# DSH Desktop v0.2.5

本版本修复了 v0.2.x 更新链路的关键缺陷，并加固了多处健壮性问题。
详细验证记录见 [`docs/verification/2026-08-27-update-restart-and-robustness-fixes.md`](../verification/2026-08-27-update-restart-and-robustness-fixes.md)。

## 修复

- **DSH 更新现在真正切换版本（严重）**：此前“立即重启生效 / 自动应用”与
  “回滚到上一版”调用的重启路径始终使用应用启动时缓存的旧版本——界面报告
  成功，但实际进程仍在运行旧版本，且“新版本健康验证失败自动回滚”从未对
  新版本生效。现在每次原地重启都会从磁盘重新解析当前选中的发行版。
- **镜像与代理设置即时生效**：npm registry 镜像、HTTP(S) 代理在设置保存后
  立即作用于后续的更新检查与安装，不再需要重启桌面应用；定时检查更新
  也已携带镜像参数。
- **配置文件损坏可自愈**：current.json / previous.json / 运行时清单等指针
  文件损坏时按“未选择”降级并自动回退（重新解压/重装），不会卡死启动。
- **启动失败后的状态残留**：DSH 启动失败后正确复位内部状态，再次双击
  打开程序会触发恢复尝试，而不是只把窗口带到前台。
- **后台更新通知更可靠**：点击“立即重启生效”后若执行失败，会通过系统
  通知明确告知，不再静默丢失。
- **测试模式数据隔离**：测试模式下跳过旧版用户数据迁移，避免移动真实
  `%LOCALAPPDATA%` 数据。

## 其他

- 构建脚本与测试统一使用 System32 bsdtar 绝对路径，Git Bash 环境下
  `npm test` / `npm run dist:win` 不再受 PATH 中 GNU tar 干扰；
- README 全面重写为面向用户与开发者的完整项目介绍；
- Release 说明改为按版本维护（`docs/release-notes/<tag>.md`）。
