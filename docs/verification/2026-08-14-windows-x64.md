## 6. Rollback

DSH rollback is available in the application through **帮助 → 回滚到上一个 DSH
版本**. It restores the previous validated pointer, restarts the service, and
requires the restored service to pass the health check.

For a desktop rollback, retain the previous installer and its published SHA-256,
then run:

```powershell
& 'C:\Users\1\Documents\ChatGPT\DSH TUI\scripts\rollback-desktop.ps1' `
  -InstallerPath 'C:\path\to\previous\DSH-Desktop-<version>-Setup.exe' `
  -ExpectedSha256 '<64-hex-sha256>'
```

The script resolves the installer, enforces the `.exe` type, verifies the exact
SHA-256, waits for the installer, and treats a nonzero installer status as failure.
